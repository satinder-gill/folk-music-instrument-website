##  About The Project

**Folk Rhythms of India** is a beautifully designed web application that lets users **explore and play traditional Indian musical instruments**.

From the energetic **Dhol** to the soothing **Bansuri**, this project brings Indian folk culture to life through **interactive audio playback and modern UI design**.

---

##  Features

- Play real instrument sounds (audio integration)
- Instrument gallery with images & descriptions
- Play / Pause functionality (one audio at a time)
- Fully responsive design
- Contact form with success message
- Smooth UI animations & hover effects
